# 말씀의 여정 — 성경읽기 체크 PWA

시편 28편(2026-08-07)부터 시작해 **구약 9/11**, **신약 11/30** 완독을 목표로 하는
성경 1독 체크 웹앱입니다. 개역한글판 각 장의 실제 글자수를 기준으로 하루 분량을 균등하게 배분했습니다.

토요일·일요일·공휴일·대체공휴일(광복절 연휴, 추석 연휴, 개천절 연휴, 한글날 연휴)은
쉬는 날로 일정에서 제외됩니다.

- 구약(시편 28편 ~ 말라기): 읽는 날 25일, 하루 약 15,300자
- 신약(마태복음 ~ 요한계시록): 읽는 날 52일, 하루 약 6,200자

## 파일 구성

| 파일 | 설명 |
|---|---|
| index.html | 앱 본체 (HTML+CSS+JS 단일 파일) |
| manifest.json | PWA 매니페스트 (홈 화면 설치용) |
| sw.js | 서비스워커 (오프라인 캐시 + 백그라운드 알림) |
| icon-*.png | 앱 아이콘 |

## 배포 방법 (PWA 설치에는 HTTPS가 필요합니다)

가장 간단한 방법은 **GitHub Pages**입니다.

1. GitHub에 새 저장소를 만들고 이 폴더의 파일 전체를 업로드
2. 저장소 Settings → Pages → Branch를 `main`(root)으로 설정
3. 1~2분 후 `https://아이디.github.io/저장소명/` 으로 접속

사내 웹서버(Apache 등)에 올려도 되지만, **HTTPS가 아니면 설치·알림이 동작하지 않습니다**
(localhost는 예외).

## 스마트폰 설치 (Android Chrome)

1. Chrome으로 배포 주소 접속
2. 앱 내 "알림 설정" 탭 → **설치** 버튼, 또는 Chrome 메뉴(⋮) → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행하면 독립 앱처럼 동작

## 알림 동작 방식

- "알림 설정" 탭에서 **알림 권한 허용**을 누르고, 알림 시간(기본 오후 9시)을 선택하세요.
- 설정한 시간부터 오후 11시 사이에 오늘 분량이 미완료면 알림이 옵니다.
- 알림 경로는 두 가지입니다:
  1. **앱(탭)이 열려 있을 때**: 설정 시각에 정확히 알림
  2. **앱이 닫혀 있을 때**: Chrome의 주기적 백그라운드 동기화(Periodic Background Sync)로
     약 1시간 간격으로 확인 후 알림. 이 기능은 **홈 화면에 설치**되어 있고
     해당 사이트를 자주 사용할수록 안정적으로 동작합니다(Chrome 정책).
- 웹 기술 특성상 앱을 설치하지 않고 브라우저 탭도 닫아두면 알림이 오지 않을 수 있습니다.
  홈 화면 설치를 권장합니다.

## 데이터 저장

읽기 기록은 브라우저 localStorage에만 저장됩니다(서버 전송 없음).
브라우저 데이터를 삭제하면 기록도 삭제되니 주의하세요.
