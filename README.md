# 말씀의 여정 — 성경읽기 체크 (1독 앱)

2026년 성경 1독의 남은 여정(시편 28편 → 요한계시록)을 완주하기 위한 체크 PWA입니다.
스마트폰 홈 화면에 설치해 앱처럼 사용합니다.

## 읽기 일정 (고정)

| 구분 | 기간 | 읽는 날 | 하루 분량 |
|---|---|---|---|
| 구약 (시편 28편~말라기) | 2026-08-07 ~ 09-11(금) | 25일 | 평균 15,303자 (6~31장) |
| 신약 (마태복음~계시록) | 2026-09-14(월) ~ 11-30(월) | 52일 | 평균 6,221자 (약 3~5장) |

- **토·일요일과 공휴일·대체공휴일은 쉬는 날**입니다: 광복절 연휴(8/15~17),
  추석 연휴(9/24~27), 개천절 연휴(10/3~5), 한글날 연휴(10/9~11)
- 하루 분량은 **개역한글판 각 장의 실제 글자수** 기준으로 균등 배분했습니다.
  (짧은 시편 구간은 하루 15~23장, 긴 이사야 구간은 하루 8장이지만 읽는 양은 동일)

## 주요 기능

### 오늘 읽기
- 장별 체크박스, 절수 표시, 책별 그룹핑
- **드래그 연속 체크**: 체크박스를 누른 채 쓸어내리거나, 장을 길게 눌러(300ms) 여러 장 한 번에 체크/해제
- 진행 링 + 오늘 분량 요약 (총 장/절 · 읽음 · 남음 글자수)
- 밀린 분량 자동 안내(해당 날짜로 이동), 쉬는 날 안내 배너
- 날짜 이동으로 지난/미래 분량 미리 체크 가능
- 상단 **여정 리본**: 글자수 기준 전체 진행률, 책 경계 눈금, 오늘 목표 지점 마커
- 구약 구간은 상록색, 신약 구간은 청람색 테마 자동 전환

### 전체 일정
- 읽는 날만 월별로 표시, 완료(✓)/부분(숫자) 상태
- 열면 오늘 위치로 자동 스크롤 + "📍 오늘 위치" 플로팅 버튼

### 알림
- 알림 시간 다중 선택: **오후 12:40 / 10:00 / 10:30 / 11:00**
- 선택 시각에 오늘 분량이 남아 있으면 알림 (완료했거나 쉬는 날이면 발송 안 함)
- 앱이 닫혀 있을 때는 주기적 백그라운드 확인(홈 화면 설치 + 자주 사용 시 안정적)
- 상단바 전용 배지 아이콘(책 모양), 확인 전까지 알림 유지, 재발송 시 다시 울림
- 팝업이 안 뜰 때: ① 앱을 보고 있는 동안에는 안드로이드가 팝업 생략 —
  테스트 버튼(5초 후 발송)을 누르고 홈으로 나가서 확인
  ② 알림 길게 누르기 → 알림 유형 "소리 및 팝업" ③ 방해금지 모드 확인

### 읽어주기 (개역한글 낭독)
- **쉬운성경 함께 보기**: 설정에서 쉬운성경.json을 가져오면(기기에만 저장, 공개 배포 금지)
  읽어주기 화면에서 절을 누르거나 [쉬운성경] 버튼으로 쉬운 번역을 함께 표시

- **남성/여성 음성 선택** — Google Cloud TTS(Chirp 3 HD)로 사전 생성한 MP3 재생
- 재생 우선순위: ① 폰에 저장한 음원 → ② 웹(GitHub) 음원 → ③ 기기 TTS 폴백
- 절 번호와 본문 표시, 현재 절 하이라이트(MP3는 글자수 비율 근사) + 자동 스크롤
- 배속 0.8~1.5, 일시정지 후 이어 듣기, 장 완료 시 **자동 체크** 후 다음 장 연속 재생
- 재생 중 화면 꺼짐 방지(Wake Lock)
- 설정 탭 "낭독 음원 관리"에서 MP3를 폰에 저장(오프라인 재생, 데이터 소모 없음)

## 배포 / 설치

1. 이 폴더 전체를 GitHub 저장소에 업로드 → Settings → Pages → main(root) 활성화
2. `https://아이디.github.io/저장소명/` 접속 (PWA·알림은 HTTPS 필수)
3. 스마트폰 Chrome → 메뉴 → **홈 화면에 추가**
4. 앱 업데이트: 파일을 덮어쓰면 다음 실행 시 자동 반영 (안 되면 앱 완전 종료 후 재실행)

## 낭독 음원 만들기 (선택)

`tts_generate.py`(배포 제외, PC 보관)로 생성합니다. Google Cloud에서
Text-to-Speech API 사용 설정 + API 키 발급 후:

```
python tts_generate.py --key 키 --preview --voice ko-KR-Chirp3-HD-Kore   # 미리듣기
python tts_generate.py --key 키 --voice ko-KR-Chirp3-HD-Kore --out audio/female
python tts_generate.py --key 키 --voice ko-KR-Chirp3-HD-Orus --out audio/male
```

- 중단해도 재실행하면 완성된 장은 건너뛰고 이어서 생성
- 개역한글 특성 보정 포함: 절 끝 마침표 부여, 쉼표→마침표(호흡), 긴 절 분할, 괄호 제거
- Chirp 3 HD 무료 한도는 월 100만 자(등급별 별도), 전량 약 93.7만 자
- 완성된 audio 폴더는 GitHub에 올리거나(음성당 저장소 1개 권장, Pages 1GB 제한),
  앱의 "낭독 음원 가져오기"로 폰에 직접 저장

## 데이터·저장

- 읽기 기록·설정은 이 기기 브라우저(localStorage)에만 저장, 서버 전송 없음
- 폰 저장 음원은 IndexedDB(브라우저 데이터 삭제 시 함께 삭제 → 다시 가져오면 됨)
- 개역한글판(1961)은 저작권이 만료된 공개 본문입니다
