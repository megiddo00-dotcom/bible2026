# 말씀의 여정 — 성경읽기 체크 (1독 앱)

2026년 성경 1독의 남은 여정(시편 28편 → 요한계시록)을 완주하기 위한 체크 PWA입니다.
스마트폰·태블릿 홈 화면에 설치해 앱처럼 사용합니다. (초록 아이콘)

## 읽기 일정 (고정)

| 구분 | 기간 | 읽는 날 | 하루 분량 |
|---|---|---|---|
| 구약 (시편 28편~말라기) | 2026-08-07 ~ 09-11(금) | 25일 | 평균 15,303자 (6~31장) |
| 신약 (마태복음~계시록) | 2026-09-14(월) ~ 11-30(월) | 52일 | 평균 6,221자 (약 3~5장) |

- **토·일요일과 공휴일·대체공휴일은 쉬는 날**: 광복절 연휴(8/15~17), 추석 연휴(9/24~27),
  개천절 연휴(10/3~5), 한글날 연휴(10/9~11)
- 하루 분량은 **개역한글판 각 장의 실제 글자수** 기준 균등 배분

## 주요 기능

### 오늘 읽기
- 장별 체크박스(절수 표시, 책별 그룹핑), **드래그 연속 체크**(체크박스를 누른 채 쓸어내리기
  또는 장 길게 누르기)
- 진행 링 + 오늘 분량 요약(총 장/절 · 읽음 · 남음 글자수)
- 밀린 분량 안내(해당 날짜로 이동), 쉬는 날 배너, 날짜 이동으로 과거/미래 분량 체크
- 상단 **여정 리본**(글자수 진행률, 책 경계 눈금, 오늘 목표 마커)
- 구약=상록색 / 신약=청람색 테마 자동 전환

### 전체 일정
- 읽는 날만 월별 표시, 완료(✓)/부분(숫자) 상태
- 열면 오늘 위치로 자동 스크롤 + "📍 오늘 위치" 플로팅 버튼

### 알림
- 알림 시간 다중 선택: **오후 12:40 / 10:00 / 10:30 / 11:00**
- 오늘 분량이 남아 있을 때만 발송 (완료·쉬는 날엔 발송 안 함)
- 앱이 닫혀 있어도 주기적 백그라운드 확인(홈 화면 설치 시 안정적)
- 책 모양 상단바 배지, 확인 전까지 유지, 재발송 시 다시 울림
- 테스트는 **5초 후 발송** — 누르고 홈 화면으로 나가서 확인
  (앱을 보고 있는 동안에는 안드로이드가 팝업을 생략함)

### 읽어주기 (개역한글 낭독)
- 읽기 화면 상단 두 줄 구성: 1줄 = 성경 이름·장(말줄임 없음) / 2줄 = [쉬운성경][음성][배속]
- **남성/여성 음성 선택** — Chirp 3 HD로 사전 생성한 MP3 재생.
  우선순위: ① 폰에 저장한 음원 → ② 웹(GitHub) 음원 → ③ 기기 TTS 폴백
- 현재 절 하이라이트(MP3는 글자수 비율 근사) + 자동 스크롤, 배속 0.8~1.5,
  이어 듣기, 장 완료 시 **자동 체크** 후 연속 재생
- **쉬운성경 함께 보기**: 설정에서 쉬운성경.json을 가져오면(기기에만 저장, 공개 배포 금지)
  절을 누르거나 [쉬운성경] 버튼으로 쉬운 번역을 테라코타색 박스로 함께 표시
- **화면 켜짐 유지 설정**: "읽는 동안 화면 항상 켜기" 켬(기본) = 읽기 화면이 열려 있는 동안
  항상 유지 / 끔 = 음성 재생 중에만 유지

### 기기 간 동기화 (폰 ↔ 태블릿)
- **자동 동기화**: GitHub 토큰(classic, gist 권한만) 하나를 양쪽 기기에 입력하면
  비공개 Gist(설명: bible-tracker-sync, 파일: btr.json)로 자동 공유
  - 앱을 열 때 + 화면 복귀 시(1분 스로틀) 자동 수신, 체크 20초 후 자동 송신
  - 병합: **체크/해제 중 더 최근 동작이 승리** — 읽음은 안전하게 합쳐지고 해제도 정확히 전파
- **수동 백업**: 기록 내보내기/가져오기(JSON 파일)

### 화면 대응
- 세로/가로 회전 모두 지원(태블릿 가로 최적화 폭·글자 크기).
  이미 설치된 앱에서 가로가 안 풀리면 한 번 재설치

## 파일 구성

| 파일 | 설명 |
|---|---|
| index.html | 앱 본체 (단일 파일) |
| sw.js | 서비스워커 (오프라인 캐시·백그라운드 알림, MP3 캐시 제외) |
| manifest.json | PWA 매니페스트 |
| krv.json | 개역한글 본문 시편28~계시록 (2.3MB) |
| icon-*.png / badge-96.png | 아이콘 / 상단바 배지 |
| audio/female·male/*.mp3 | (선택) 낭독 음원 `책id-장.mp3` |

## 배포 / 설치

1. 폴더 전체를 GitHub 저장소에 업로드 → Settings → Pages → main(root)
2. `https://아이디.github.io/저장소명/` 접속 → Chrome 메뉴 → 홈 화면에 추가
3. 업데이트: 파일 덮어쓰기 후 앱 재실행이면 자동 반영

## 낭독 음원 / 각종 키 발급
자세한 절차는 별도 문서 **「음원제작_공휴일키_안내서.docx」** 참고.
요약: Google Cloud TTS API 키 발급 → `tts_generate.py`로 미리듣기 → 전체 생성
(Kore 여성/Orus 남성, 중단·재개 가능) → GitHub 업로드 또는 앱의 "음원 가져오기"로 폰 저장.

## 데이터·저장
- 읽기 기록·설정: 기기 localStorage / 음원·쉬운성경: IndexedDB(같은 도메인의 두 앱이 공유)
- 동기화 데이터: 본인 GitHub 비공개 Gist (읽은 장 목록 수준의 정보만)
- 개역한글판(1961)은 저작권 만료 공개 본문 / **쉬운성경은 저작권 보호 대상**이라
  기기 가져오기 방식만 사용하며 저장소에 올리지 않음

## 통독 앱과의 관계
1독 완주 후에는 설정형 66권 전체판 **"말씀의 여정 — 성경 통독"**(남색 아이콘)을 사용.
같은 도메인 배포 시 폰 저장 음원·쉬운성경 공유, 기록·설정·동기화 파일은 분리(btr vs btr2).
